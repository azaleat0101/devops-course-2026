# Git в VS Code: заметки

## Что удобно в VS Code
1. Визуальный diff — сразу видно, какие строки изменились.
2. Быстрый commit через UI: ввёл сообщение и нажал ✓.
3. GitLens показывает, кто и когда менял строку.
4. Удобное разрешение merge-конфликтов через встроенный редактор.

## Что удобнее в терминале
1. Сложные операции: rebase, cherry-pick, squash.
2. Автоматизация через скрипты.
3. Работа на сервере по SSH, где нет GUI.
