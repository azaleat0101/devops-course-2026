# SVN vs Git

## 1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?
В Git ветка — это всего лишь указатель на коммит. Создание ветки не копирует файлы, поэтому происходит мгновенно. В SVN ветка — это копирование директории в центральном репозитории, что медленнее и затратнее.

## 2. Можно ли в SVN сделать коммит без интернета? Почему?
Нет. SVN — централизованная система. Коммит отправляется на центральный сервер, поэтому без сети коммит невозможен. Можно только менять файлы локально, но не фиксировать изменения в репозитории.

## 3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?
Например, в legacy-проектах, где уже используется SVN. Также в некоторых корпоративных средах с жёстким централизованным контролем доступа, большими бинарными файлами и блокировками файлов. Но для новых проектов обычно выбирают Git.
